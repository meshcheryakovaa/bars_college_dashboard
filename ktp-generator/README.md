# КТП по группам

Откройте `index.html` из скачанной папки. Приложение работает локально, включая упаковку файлов в ZIP. Первая группа заполнена по образцу СП-1-25р.

1. Введите в первом столбце реквизиты листа «Общая». Группу указывайте полностью, как в БАРС, например «СП-1-25р - 1 курс».
2. Нажмите «Добавить группу», чтобы скопировать общие реквизиты в следующий столбец. При необходимости отредактируйте их.
3. Проверьте автоматически составленные названия осеннего и весеннего КТП. Любое из них можно вписать вручную.
4. Нажмите «Скачать все файлы ZIP». На каждую группу формируются две книги Excel 97–2003 из соответствующих семестровых шаблонов. Введённые данные хранятся до закрытия или перезагрузки страницы.

В `templates.js` встроены оба исходных XLS. Модуль `workbook.js` рассчитан на структуру этих двух книг.
