# Дашборд журналов «Электронного колледжа»

Распаковываемое расширение Manifest V3, версия **1.2.0**. Собирает списки студентов и занятия из открытых журналов теоретических занятий, сохраняет их в профиле браузера и показывает на отдельной вкладке. Для выбранной группы расширение может автоматически перебрать предметы. Также доступен ручной сбор и экспорт в Excel.

## Установка

1. Скачайте ZIP репозитория через **Code → Download ZIP** или клонируйте репозиторий.
2. Откройте `browser://extensions` в Яндекс Браузере, `chrome://extensions` в Chrome или `edge://extensions` в Edge.
3. Включите режим разработчика и выберите **«Загрузить распакованное расширение»**. Укажите [папку `college-journal`](college-journal), в которой лежит `manifest.json`. Сборка, npm и сервер для установки не требуются.

Если расширение уже установлено, замените файлы в существующей папке, нажмите **«Обновить»** на странице расширений и перезагрузите вкладку колледжа перед новым запуском. Обновление той же установки позволяет использовать ранее собранные записи.

## Сбор для одной группы

1. Войдите в «Электронный колледж» обычным способом. Откройте **«Журнал теоретических занятий»**, выберите нужную группу и оставьте активной вкладку **«Журнал»**.
2. В меню расширения нажмите **«Собрать журналы группы»**. Группу выбирает пользователь, предметы этой группы перебирает расширение. Во время обхода оставьте окно журнала открытым.
3. В меню можно увидеть текущий предмет, прогресс и причину остановки. Кнопка **«Остановить автосбор»** прекращает дальнейший обход. При ошибке уже собранные записи доступны.
4. Нажмите **«Открыть дашборд»**. В нём есть таблицы журналов, студентов и занятий, поиск и фильтр по журналу. Таблицы обновляются после сохранения каждой записи. **«Скачать Excel»** выгружает те же данные в книгу с тремя листами.

Для ручного обхода нажмите **«Запустить ручной сбор»** и последовательно открывайте журналы в той же вкладке. После полной перезагрузки страницы сбор нужно запустить заново.

Данные хранятся локально в профиле браузера. Дашборд получает уже сохранённые записи. Выгрузка может содержать Ф. И. О. и ID студентов, поэтому примеры в документации используют вымышленные значения.
