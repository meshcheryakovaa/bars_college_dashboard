# Дашборд журналов «Электронного колледжа»

Распаковываемое расширение Manifest V3, версия **1.5.1**. Собирает списки студентов и занятия из открытых журналов теоретических и практических занятий, сохраняет их в профиле браузера и показывает на отдельной вкладке. Для выбранной группы расширение может автоматически перебрать предметы. Также доступен ручной сбор и экспорт в Excel.

## Установка

1. Скачайте ZIP репозитория через **Code → Download ZIP** или клонируйте репозиторий.
2. Откройте `browser://extensions` в Яндекс Браузере, `chrome://extensions` в Chrome или `edge://extensions` в Edge.
3. Включите режим разработчика и выберите **«Загрузить распакованное расширение»**. Укажите [папку `college-journal`](college-journal), в которой лежит `manifest.json`. Сборка, npm и сервер для установки не требуются.

Если расширение уже установлено, замените файлы в существующей папке, нажмите **«Обновить»** на странице расширений и перезагрузите вкладку колледжа перед новым запуском. Обновление той же установки позволяет использовать ранее собранные записи.

## Справочник и выбор групп

Откройте дашборд из меню расширения на вкладке колледжа. Раскройте список групп на сайте и нажмите **«Считать список групп»** на дашборде. В разделе **«Группы»** поставьте отметки **«Для анализа»**. Фильтр **«Только отмеченные группы»** действует на все таблицы и счётчики дашборда. Настройки сохраняются после закрытия вкладки.

Нажмите **«Собрать отмеченные группы в обоих журналах»**. Расширение откроет теоретический журнал и пройдёт отмеченные группы текущего сайта и учебного периода, затем откроет практический журнал и повторит обход. При запуске активируется вкладка колледжа. Дашборд показывает текущий журнал, группу, дисциплину и число пройденных сочетаний журнала и группы. Если сайт не открыл нужную группу автоматически, выберите указанную группу вручную в той же вкладке.

Чтобы заполнить дисциплины и состав студентов отдельной группы, откройте нужную группу на сайте и нажмите **«Собрать открытую группу»** на дашборде. Названия дисциплин сохраняются из загруженного списка сразу. Студенты добавляются по мере чтения каждого журнала.

Команда **«Сохранить БД в папку расширения»** предлагает выбрать файл `catalog-db.json`. Если браузер выдал разрешение, файл обновляется при изменениях, пока открыт дашборд. Для разового сохранения доступна кнопка **«Скачать БД»**. Файл содержит Ф. И. О. и ID студентов и исключён из Git.

## Даты и очистка базы

В дашборде выберите **«С»** и **«По»**. По умолчанию используется период с **01.09.2026** по сегодняшнюю дату. Автосбор применяет диапазон в каждом журнале до выбора группы и дисциплины. Для ручной работы нажмите **«Применить даты в журнале»**, дождитесь подтверждения и затем выбирайте группу и дисциплину. Собранные журналы накапливаются независимо от смены диапазона.

**«Очистить базу дашборда»** после подтверждения удаляет локальные журналы, справочники и отметки групп. Очистка останавливает текущий сбор. Диапазон дат сохраняется. Если к дашборду подключён файл `catalog-db.json` с доступом на запись, в него будет записан пустой справочник.

## Сбор для одной группы

1. Войдите в «Электронный колледж» обычным способом. Откройте нужный журнал, примените диапазон дат, выберите группу и оставьте активной вкладку **«Журнал»**.
2. В меню расширения нажмите **«Собрать журналы группы»**. Группу выбирает пользователь, предметы этой группы перебирает расширение. Во время обхода оставьте окно журнала открытым.
3. В меню можно увидеть текущий предмет, прогресс и причину остановки. Кнопка **«Остановить автосбор»** прекращает дальнейший обход. При ошибке уже собранные записи доступны.
4. Нажмите **«Открыть дашборд»**. В нём есть таблицы журналов, студентов и занятий, поиск и фильтр по журналу. Таблицы обновляются после сохранения каждой записи. **«Скачать Excel»** выгружает те же данные в книгу с тремя листами.

Для ручного обхода нажмите **«Запустить ручной сбор»** и последовательно открывайте журналы в той же вкладке. После полной перезагрузки страницы сбор нужно запустить заново.

Данные хранятся локально в профиле браузера. Дашборд получает уже сохранённые записи. Выгрузка может содержать Ф. И. О. и ID студентов, поэтому примеры в документации используют вымышленные значения.
