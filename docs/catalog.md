# Справочник и локальная БД

## Откуда поступают данные

| Данные | Что нужно открыть | Что сохраняется |
| --- | --- | --- |
| Группы | Выпадающий список групп на вкладке колледжа | Название группы, учебный период, адрес сайта |
| Дисциплины | Журнал конкретной группы | Готовый список предметов из хранилища Ext JS, включая подписи и значения вариантов |
| Студенты | Загруженные журналы группы | ID и Ф. И. О. После чтения нескольких дисциплин один студент показывается один раз внутри группы |
| Занятия | Загруженные журналы дисциплин | Номера, даты и ID занятий в записях журналов |

Кнопка **«Считать список групп»** ждёт появления и стабилизации списка. Если на странице остались несколько подходящих списков, приоритет у единственного открытого. На сайте группу выбирает пользователь. Команда **«Собрать открытую группу»** последовательно обходит дисциплины только в открытом журнале группы.

Число студентов в справочнике означает количество уже найденных записей. Одинаковый ID студента объединяется внутри группы. Если в журнале отсутствовала подпись группы, студент виден без группы при выключенном фильтре. Подпись берётся из выпадающего списка, когда выбранное значение определяется однозначно.

## Выбор групп

В разделе **«Группы»** отметьте нужные строки. Отметка привязана к сочетанию сайта, учебного периода и названия группы. Суффикс с курсом используется в отображении. Включите **«Только отмеченные группы»**, чтобы сузить таблицы и счётчики дашборда. Фильтр управляет просмотром. Кнопка сбора отмеченных групп использует отметки даже при выключенном фильтре.

## Сбор отмеченных групп

Откройте дашборд из вкладки колледжа, отметьте нужные группы и нажмите **«Собрать отмеченные группы в обоих журналах»**. В очередь попадут отметки текущего сайта и учебного периода. Сначала расширение открывает теоретический журнал, затем практический. В каждом оно применяет даты, переключает отмеченные группы и собирает их дисциплины.

Дашборд показывает тип журнала, текущую группу и число пройденных сочетаний группы и журнала. Пропуски перечисляются после завершения. Если автоматическое переключение не удалось, выберите указанную группу вручную в той же вкладке. На появление нужного журнала отводится до двух минут. При остановке или ошибке уже собранные данные сохраняются.

## Хранение

Рабочие данные сохраняются в `chrome.storage.local`. Записи старых версий с ключами `journal:<sha256>` читаются в новой версии. Справочник строится из таких записей и из ключей `catalog:group:…`. Выбор хранится в `catalog:selected:…`, а режим фильтра — в `catalog:show-selected`.

Чтобы сохранить файловую БД, нажмите **«Сохранить БД в папку расширения»** и укажите `catalog-db.json`. При наличии разрешения браузера дашборд записывает свежий справочник при сохранении журналов, добавлении групп и изменении отметок. Закрытие дашборда прекращает обновление файла, но рабочая БД в браузере продолжает сохраняться. При следующем открытии дашборд обновит файл, если доступ на запись ещё есть. При отсутствии поддержки сохранения напрямую используйте **«Скачать БД»**.

```json
{
  "schemaVersion": 1,
  "unassignedStudents": [],
  "groups": [
    {
      "key": "[\"https://college.example\",\"2026/2027\",\"ДЕМО-1-26\"]",
      "origin": "https://college.example",
      "period": "2026/2027",
      "name": "ДЕМО-1-26 - 1 курс",
      "selected": true,
      "disciplines": [{"id": "10001", "name": "Демонстрационная дисциплина"}],
      "students": [{"id": "90001", "name": "Учебный Пример"}]
    }
  ]
}
```

Файл представляет собой снимок справочника. Его редактирование не меняет рабочие данные браузера. Файл `catalog-db.json` исключён из отслеживания Git.

Кнопка **«Очистить базу дашборда»** запрашивает подтверждение, удаляет локальные данные и отметки и останавливает активный сбор. Подключённый файловый снимок обновляется до пустого справочника при наличии доступа на запись. Отдельно скачанные копии остаются на диске.
