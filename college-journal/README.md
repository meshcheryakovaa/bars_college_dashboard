# Сборщик журналов колледжа

1. Распакуйте ZIP. В Chrome откройте `chrome://extensions`, в Edge — `edge://extensions`, в Яндекс Браузере — `browser://extensions`.
2. Включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку `college-journal` с файлом `manifest.json`.
3. Войдите в «Электронный колледж», выберите одну группу вручную и откройте вкладку «Журнал» в журнале теоретических занятий. В меню расширения нажмите «Собрать журналы группы».
4. Дождитесь сообщения «Автосбор завершён». Расширение по очереди перебирает предметы открытой группы и сохраняет каждый доступный журнал после загрузки новой таблицы. Ожидание списка и каждой таблицы ограничено 60 секундами. При ошибке автосбор останавливается, уже сохранённые записи остаются доступны. Во время автосбора оставьте вкладку колледжа открытой и не переключайте в ней группу, предмет или раздел.
5. Нажмите «Открыть дашборд», чтобы смотреть сохранённые журналы, студентов и занятия на отдельной вкладке. Данные обновляются после каждого сохранения. На дашборде доступны поиск и выбор журнала.
6. При необходимости нажмите «Скачать Excel». Книга содержит листы «Журналы», «Студенты» и «Занятия». «Остановить автосбор» завершает обход. Чтобы самостоятельно открывать журналы, нажмите «Запустить ручной сбор». После полной перезагрузки сайта любое действие нужно запустить заново.

Данные хранятся в текущем профиле браузера. Автосбор выбирает предметы через интерфейс сайта. Расширение считывает таблицы после их штатной загрузки. Запуск сбора нужен отдельно в каждой вкладке.

Повторное открытие совпадающего предмета с тем же набором ID студентов за тот же учебный период обновляет запись. Занятия объединяются по ID. Если изменится состав студентов, появится отдельная запись. «Группа (подсказка)» берётся из списка выбора при наличии однозначного значения и служит ориентиром. Дата занятия сохраняется так, как показана в журнале. Выгрузка содержит Ф. И. О. студентов и их идентификаторы.

Для обновления распакованного расширения замените его файлы в той же папке. На странице расширений нажмите «Обновить» и запустите сбор снова.
