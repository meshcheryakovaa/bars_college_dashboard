# Исследование интерфейса БАРС

Распакуйте архив. В Chrome, Edge или Яндекс Браузере откройте страницу расширений, включите режим разработчика и нажмите «Загрузить распакованное расширение». Выберите папку journal-inspector с manifest.json.

1. Войдите в колледж. На рабочем столе БАРС откройте меню расширения и нажмите «Начать запись». Закройте меню.
2. Откройте теоретический журнал, установите «С» и «По», примените диапазон. Выберите группу и предмет. Между шагами дожидайтесь обновления таблицы.
3. Откройте практический журнал, повторите выбор и проверьте дату после смены группы.
4. В меню нажмите «Остановить», затем «Скачать отчёт JSON». Скачайте файл перед закрытием вкладки. Полная навигация завершает сеанс, предыдущая запись этой вкладки доступна до запуска новой.

Каждый элемент steps описывает click, dblclick или change. element содержит тип узла, классы Ext JS, известную подпись и позицию среди соседей. before и after показывают состояние при обработке события и последнее наблюдение до следующего шага. Для change значение поля уже могло измениться. Сравнивайте fields, tab, leftRows, rightRows, listSizes и loading. Размеры таблиц относятся к строкам DOM, в том числе при частичной отрисовке. Быстрые промежуточные состояния могут пропускаться.

requests содержит завершившиеся fetch/XHR из Resource Timing основной страницы: путь и имена параметров, тип инициатора, время начала от старта записи, длительность, доступный код ответа и размер закодированного тела в байтах. Ноль байт и null для статуса возможны при ограничении браузером доступа к метаданным. Связь со шагом приблизительная, по времени начала. Фоновые запросы могут совпадать с нажатием. Запросы до первого действия вынесены на верхний уровень. Дождитесь завершения загрузки перед остановкой.

Содержимое ячеек, тела запросов и ответов, заголовки и значения параметров URL не записываются. В файле остаются адрес сайта, пути, названия выбранных группы и предмета, даты. Запись хранится в памяти сеанса браузера для этой вкладки. Пределы отчёта — 300 действий и 30 запросов на действие (лишние учитываются в omittedRequests). Вложенные документы и новые вкладки требуют отдельного исследования.
